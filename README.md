# PackMovers

Mobile-first moving & logistics app home screen (static HTML + Tailwind CDN).

## Structure
- `index.html` - page markup
- `src/css/styles.css` - custom styles
- `src/js/tailwind-config.js` - Tailwind theme (colors, fonts, spacing)

## Run
Open `index.html` in a browser, or `python -m http.server` and visit http://localhost:8000.
